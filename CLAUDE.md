# Rift Library

Plain HTML/CSS/JS site (no build step) served by GitHub Pages from `main`.

## Formatting and lint

- Code is formatted with Prettier (`.prettierrc.json`) and linted with ESLint (`eslint.config.mjs`).
- Before committing, run `npm install` once, then `npm run format` and `npm run check`.
- CI (`.github/workflows/check.yml`) fails a PR whose files aren't Prettier-formatted or that has lint errors.
- `cards.json` is generated by `scripts/build-cards.js` and intentionally left minified; don't format it.
